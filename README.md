# CPP DSA Practice

A simple C++ repository for daily DSA streak practice.

## Daily streak plan
- Day 1: Arrays
- Day 2: Strings
- Day 3: Recursion
- Day 4: Sorting
- Day 5: Hashing

## Compile and run
```bash
g++ main.cpp -o dsa
./dsa
```

## Notes
Each file focuses on a small problem pattern to help build consistency.
